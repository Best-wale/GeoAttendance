# GeoAttendance

## Overview

**GeoAttendance** is a location-based attendance tracking web application designed to efficiently monitor and manage attendance for students, employees, and event participants. By utilizing geolocation services, this system ensures users can check in only when physically present at the designated location.

## Features

- **Geolocation-Based Check-in:** Users can only mark attendance within defined geographical locations.
- **Real-Time Tracking:** Admins can view live attendance logs.
- **Secure Authentication:** Login system to prevent unauthorized check-ins.
- **Modern UI with Tailwind CSS:** A sleek, responsive design for an intuitive user experience.
- **Attendance Reports:** Generates structured records of attendance history.

## Technologies Used

- **HTML** – Structure of the web application.
- **CSS (Tailwind CSS)** – Styling for modern, responsive UI.
- **JavaScript** – Handles geolocation logic and interactivity.
- **Google Maps API** – Used for location-based validation.
